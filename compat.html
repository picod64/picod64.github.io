Compatibility tests

What has been run on PicoD64, and the result.

How

  • A real PAL C64, with the firmware in firmware (v0.2, 150 MHz). Not tested on NTSC.
  • PicoD64 the only device on the serial bus. Some fast loaders fail with another drive or interface on the bus, on a real 1541 too.
  • Each title started from a reset C64 with its RAM set to a power-up pattern, then LOAD"*",8,1 and RUN; the next disk put in as the knob's long press does. Pass: it runs to its end (or its own pass screen) as it does in VICE. Transwarp's Menu and the Testsuite ran unattended, judged from the screen.
  • Runs counts every run on this firmware, passed or not.

Copy protection: D64 error bytes

A D64 that ends in error bytes has them built into the disk, so a protection that reads them finds them. Each title below stops at READY, or on its title screen, with the error bytes removed. Loaded with LOAD"*",8,1 from a freshly reset C64.

Title Errors its protection reads Runs Result

JiffyDOS

JiffyDOS 6.01 KERNAL in the C64. "Both sides" means JiffyDOS's 1541 ROM on the card as dos1541.bin as well. The fill test: self-checking programs of 154 blocks on one D64; each checks every byte it loaded.

Test JiffyDOS on Result
Fill test, 2 files C64 only (stock drive ROM) ✅ every byte right, 98-101 s a file (stock speed)
Fill test, 4 files both sides ✅ every byte right, 18-20 s a file
Transwarp v0.86: Menu, entry 1 both sides ✅ 3 of 3
The browser; Ghosts'n Goblins from a D64 both sides ✅
Summer Games II, Rainbow Islands (error bytes) both sides ✅ load
