PicoD64 rev 1.1 — what to buy (one board)

Farnell order file (CSV) LCSC order file (untested)

At farnell.com, use the order file in the basket's upload (BOM) tool. The list below is what goes on the board.

Farnell is the tested source. The first boards were built from Farnell parts; upload the Farnell order file (every part, optional ones included) at farnell.com. the LCSC order file (untested) is an LCSC alternative that has never been ordered: where LCSC lacks a part it substitutes an equivalent, and the Pico 2 and the DIN sockets aren't on LCSC at all (buy them elsewhere). Check it against this list before ordering. Both files are made by gen/bom_upload.py. This page is the short list of fitted parts.

Fitted parts only. Not-fitted options are in picod64-bom.csv.
